# Banking Data Analytics & Risk Insights

## Project Overview

A banking data analytics project developed using Power BI to analyze customer accounts, transactions, financial activity, and risk-related indicators.

The project transforms raw banking data into interactive dashboards and actionable insights using data cleaning, modeling, DAX, and visualization.

---

## Objectives

- Analyze banking transactions and customer accounts
- Understand transaction and customer behavior
- Identify financial and risk-related patterns
- Analyze branch and account performance
- Create meaningful KPIs using DAX
- Build an interactive Power BI dashboard
- Generate actionable business insights

---

## Tools & Technologies

- Power BI
- DAX
- Power Query
- Excel / CSV
- Data Analysis & Visualization

---

## Data Analysis

### Transaction Analysis

- Analyzed transaction volume and transaction values
- Studied transaction types and status
- Identified transaction trends and patterns
- Examined high-value transactions

### Customer Analysis

- Analyzed customer demographics and account information
- Studied customer financial activity
- Segmented customers based on available attributes
- Identified high-value customer segments

### Financial & Risk Analysis

- Analyzed credit scores and loan-related information
- Examined interest rates and financial indicators
- Identified patterns across different customer segments
- Compared financial activity across accounts

### Branch Analysis

- Compared banking activity across branches
- Analyzed transaction performance
- Identified differences in branch-level activity

---

## Key KPIs

- Total Customers
- Total Transactions
- Total Transaction Amount
- Average Transaction Value
- Total Account Balance
- Average Credit Score
- Loan Amount
- Interest Rate

---

## Key Insights

- Identified transaction patterns across different periods and transaction types
- Highlighted customers and segments with higher financial activity
- Compared branch-level performance to understand differences in banking activity
- Analyzed credit scores to understand customer financial profiles
- Examined loan and interest-rate patterns across customers
- Identified high-value transactions and customer segments
- Used transaction status to understand successful and unsuccessful banking activity
- Converted raw banking data into interactive visual insights for easier analysis

---

## Analytical Approach

The project followed a structured data-analysis workflow:

**Data Collection → Data Cleaning → Data Transformation → Data Modeling → DAX Analysis → Visualization → Insights**
