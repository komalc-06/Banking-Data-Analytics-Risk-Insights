# Banking Data Analytics & Risk Insights

## Overview

A Power BI project analyzing banking customers, accounts, transactions, and financial risk indicators to generate actionable business insights.

## Objectives

- Analyze customer and account behavior
- Identify transaction patterns
- Evaluate balances, loans and interest rates
- Analyze credit scores and financial profiles
- Compare branch and currency-level activity
- Build interactive KPIs and dashboards

## Dataset

- **Customer Account Details:** 800 records
- **Banking Transactions:** 1,000 records
- Connected using **Account Number**

## Tools

- Power BI
- DAX
- Power Query
- Excel

## Analysis

### Customer & Financial Analysis
- Account types and balances
- Credit scores
- Loan amounts
- Interest rates

### Transaction Analysis
- Transaction types and amounts
- Transaction trends
- High-value transactions
- Currency-wise activity

### Branch Analysis
- Branch-level transaction activity
- Transaction amount comparison

## Key Insights

- Analyzed 800 customer accounts and 1,000 transactions
- Identified transaction patterns across deposits, withdrawals and transfers
- Compared customer credit scores, balances and loan exposure
- Evaluated branch and currency-level transaction activity
- Highlighted high-value transactions and customer segments

## Workflow

**Data Cleaning → Transformation → Modeling → DAX → Visualization → Insights**

## Dashboard

Interactive Power BI dashboard covering customer, transaction, financial, branch and risk-related analysis.

## Outcome

Developed practical skills in Power BI, DAX, data modeling, financial analysis, KPI development and structured reporting.

## Disclaimer

Independent portfolio project created for learning and data analytics purposes.
